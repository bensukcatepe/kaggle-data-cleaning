# Kaggle - Data Cleaning

This repo contains the Jupyter Notebook I completed during Kaggle's "Data Cleaning" course.

## What's in this Notebook?
* Handling missing values by identifying, dropping (`dropna`), or imputing them (`fillna`).
* Transforming numeric variables through scaling and normalization techniques.
* Parsing dates and converting text strings into standard `datetime` objects.
* Detecting and resolving character encoding issues (`utf-8`, `windows-1252`, etc.) using `charset_normalizer`, `.encode()`, and `.decode()`.
* Standardizing inconsistent text entries using text pre-processing (`.str.lower()`, `.str.strip()`) and fuzzy matching (`fuzzywuzzy`).
